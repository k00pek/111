# Учитель английского A2

Разговорный учитель для одного ученика. Правила лежат в `bot/instructions.md`. Темы: быт и поездки.

## Запуск

Нужен Node.js 22.13 или новее. Запускай через Node, не через Bun.

1. Установи зависимости:

```bash
npm install
```

2. Войди в Cursor один раз (без входа учитель не отвечает):

```bash
npx --yes "@grok/agent-sdk@0.6.0" login
```

3. Запусти локальный сервер:

```bash
npx --yes "@grok/agent-sdk@0.6.0" dev
```

4. Открой http://127.0.0.1:3000/playground и напиши короткую английскую фразу, например `I go to the market yesterday.`

Учитель отвечает по-английски. Если во фразе есть ошибка, он показывает одну верную фразу и ждёт, пока ты напишешь её снова. По-русски он говорит только после «скажи по-русски» или «ответь по-русски».
